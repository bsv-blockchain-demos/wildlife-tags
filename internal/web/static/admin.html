Sign in

Signing in with your wallet puts your identity key on every tag you arm, so the record says which biologist made it.

A password session is recorded as "operator" rather than as a person, so activations made this way are not attributable to a named biologist.

Arm a tag

Scan the tag's QR code, or read the id off the tag and type it.

Leaving this blank is usually the better call: whoever finds it gets to name it, and that is the part people remember. Either way the name is permanent and public.

Print a batch

Creating a batch mints keys and tag ids; it does not spend anything. Tags carry no money until they are armed on an animal. The species is a hint for the printer (a deer ear tag is not a 1×2in crab tag), and what each animal actually was is decided when the tag is armed.

Waiting to be put back in service

A tag that has just been reported sits out a cooldown before it can be claimed again. That window is the one chance to look at a report before the tag becomes claimable, so putting it back is a deliberate act.
